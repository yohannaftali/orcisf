ORCISF — APP ICON SET

Primary icon:
- master_1024.png — highest-resolution source PNG
- png/ — standard PNG sizes from 16x16 through 1024x1024
- windows/orcisf.ico — multi-size Windows icon
- macos/orcisf.icns — macOS icon (if generated successfully)
- linux/ — PNG sizes suitable for Linux desktop/application packaging
- variants/ — additional visual concepts extracted from the generated icon sheet

Recommended usage:
Windows: use the .ico file for the executable/application.
macOS: use the .icns file for the application bundle.
Linux: use the PNG files, typically the 256x256 or 512x512 version for desktop launchers.
